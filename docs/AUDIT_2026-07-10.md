## Deployment and rollback

The release uses blue-green switching:

1. Keep the existing `9208` container on `127.0.0.1:3010`.
2. Start and warm the `9276` container on `127.0.0.1:3011`.
3. Verify health, ESPA pages, images, sitemap, disabled APIs, headers, logs, and container hardening on `3011`.
4. Change only the storefront upstream in `/etc/nginx/sites-enabled/plumbing_store.conf` from `3010` to `3011`, run `nginx -t`, and reload nginx.
5. Verify the public HTTPS site before retaining the old container as the immediate rollback target.

Pre-switch backup: `/opt/plumbing_store_v2/deploy-backups/espa-20260710-precutover`.

Rollback image tag: `plumbing_store_v2-v2:rollback-pre-espa-20260710`.

Rollback does not rebuild an image: restore the backed-up storefront nginx file, validate nginx, reload, and traffic returns to the still-running container on `3010`.
